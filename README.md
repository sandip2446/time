# Meridian

A full-screen digital clock built with React, TypeScript, and Tailwind CSS — made for phone and iPad.

## Features

- **Full-screen digital clock** that fills the display
- **Portrait + landscape** — digits stack when vertical, stretch wide when horizontal
- **Sky that follows the hour** — dawn, morning, day, golden hour, dusk, night
- **Stopwatch** with lap splits to the hundredth of a second
- **Timer** with presets, custom times, and an alarm ring when finished
- Toggle **12 / 24 hour** by tapping the time

## Run

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

## Deploy (Firebase Hosting)

```bash
firebase login
npm run deploy
```
